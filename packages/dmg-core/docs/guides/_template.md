# <Вид артефакта> — гайд

**Назначение:** одно предложение — что это за артефакт и где он лежит (`<domain>/<m>/…` или `<app>/<m>/…`).

> Шаблон гайда. Копируй в `<вид>.md`, держи 40–80 строк. Код не вставляй — давай ссылки на файлы учебного модуля (`src/testing/example`). Ссылки и ID правил проверяет `scripts/docs-check.test.ts`.

---

## 1. Когда применять

3–5 пунктов: какая задача решается этим артефактом и когда выбрать другой (с ссылкой на соседний гайд).

## 2. Команда

`dmg-core gen <вид> <модуль>[.<агрегат>] [<имя>] --write` — что создаётся и какие `TODO` заполнить.

## 3. Образец

Ссылки на файлы учебного модуля (контракт, реализация, тест) с одной строкой «на что смотреть».

## 4. Чеклист правил

ID из [rules.md](../rules.md), применимые к виду, — по строке «что проверить».
