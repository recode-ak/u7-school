## Подход (отличается от `dmg-docs`)

- Основа — `architecture/docs-strategy.md`: Def несут `label`/`description`, JSDoc их не дублирует (§6); доменная документация генерируется из манифестов (`docs:domain`), описания Def для LLM — `docs:llm`. Комментарий — только «почему» и неочевидное.
- Долги: allowlist в `debt.md` или конфиге (путь/glob → `DEBT-N`) с проверкой критерия снятия вместо голых маркеров; в коде остаётся только `biome-ignore` с ID.
- `TR-NN` из кода убрать; паттерн «адаптер над legacy» описать в `migration.md` и отразить в именах. Каждый мост «временная реализация» сначала проверить на наличие записи в `debt.md`, потом убирать комментарий.
- Не делать: механический запрет комментариев линтером (обходится); массовая правка без полного прохода (замер выше — оценка).
