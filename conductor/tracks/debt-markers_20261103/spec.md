# Spec: комментарии и долги в коде u7-school

## Обзор

В коде много служебного шума: 86 голых `// DEBT-N` в 70 файлах, `TR-NN` (67 раз в 40 файлах), комментарии «временная реализация…», дублирующие `debt.md`. Трек переносит привязку долга к коду в машиночитаемый allowlist в `debt.md`, учит проверку самой видеть погашение и новый долг, убирает `TR-NN` и временные комментарии из кода, склеивает дубли реестра. Основа — заготовка `u7-comments-docs` (удалена), без части про Def и генерируемую документацию (`docs:domain`/`docs:llm` ещё не реализованы): остаток — в `conductor/architecture/migration.md` §2, строка 10+.

## Функциональные требования

1. **Allowlist в `debt.md`.** Каждая открытая запись DEBT получает машиночитаемые поля:
   - **Место** — один или несколько glob в бэктиках; поле «Погашает» допускается на уровне каждого glob;
   - **Признак** — регулярка, которой долг выражен в коде;
   - **Корень** — glob области поиска признака «вне Места» (по умолчанию — все корни проверки; исключения — перечислением в `{}`, Bun.Glob не знает `!`).

   Закрытая слиянием запись — заголовок с пометкой «слит в DEBT-N», без полей. Формат и правила — в разделе «Правила» `debt.md`.
2. **Проверка `checkDebt`** (`scripts/domain-check.ts`, вызывается в `arch:check`):
   - каждая открытая запись разбирается; Место и Признак обязательны;
   - glob Места не находит ни одного файла → ошибка (устаревшее место);
   - признак не найден в файлах **какого-либо glob** Места → ошибка «долг погашен (glob) — сними glob или закрой запись»;
   - признак найден в файле Корня вне Места → ошибка «долг без записи»;
   - `DEBT-N` в коде допустим только в `biome-ignore`, ID — открытой записи реестра; голые маркеры, упоминания в JSDoc и закрытые ID — ошибка;
   - переходный режим (голые маркеры допустимы) — только на время трека.
3. **ARC-02 без маркеров.** `checkDomainImports` больше не требует `DEBT-N` у импорта `@u7-scl/core`/`@u7-scl/app-legacy` в домене; такой импорт ловит `checkDebt` как «долг без записи» (записи DEBT-1, DEBT-2 с Корнем `domain/src/**`). Тексты ошибок чекера — без ID долгов. Отразить в `conductor/architecture/rules.md` и шапке `domain-check.ts`.
4. **Голые маркеры** `// DEBT-N` и прочие упоминания `DEBT-N` вне `biome-ignore` удалены из кода.
5. **`TR-NN` удалены из кода** (включая `runners/*/tests`). Паттерн «UC-адаптер над legacy-фасадом» (TR-11) описан в `conductor/architecture/migration.md`. Записи TR в `debt.md` §6 остаются.
6. **Комментарии «временная реализация… / уходит с миграцией»:** для каждого — проверить запись в `debt.md`; нет — черновик записи (Место, Признак) на подтверждение Нурболату; затем комментарий удалить. Комментарии «почему» остаются.
7. **Склейка дублей** — в запись с меньшим ID, Место — glob на модуль (или файл) со своим «Погашает»; остальные ID закрыты «слит в DEBT-N», номера не переиспользуются; `biome-ignore` с закрытыми ID перенумерованы:
   - импорты `@u7-scl/core` в домене: DEBT-1 ← 6, 11, 16;
   - `@u7-scl/app-legacy` в домене: DEBT-2 ← 7, 12, 17;
   - `v.isoDateTime`: DEBT-5 ← 9, 14, 19;
   - barrel'ы старых путей: DEBT-3 ← 4, 8, 13, 18, 23, 27, 30;
   - приватные члены Ar: DEBT-10 ← 15, 20.
8. **Поправки учёта** (решения Нурболата, 2026-11-03):
   - DEBT-1/2: Место — glob на модуль целиком;
   - DEBT-40: Место расширено на тесты UC/ER `modules/peer-review` (уже на `mkdtemp`);
   - DEBT-43: узкий Признак по выводу времени (`getUTCHours\(`; `view-stream`, `wish-invite`), ввод в `create-stream` и `BotUiStory.formatDate` — текстом в «Месте»;
   - DEBT-35: Место и критерий снятия приведены к коду (`it.failing` нет);
   - «последний выданный» — DEBT-43.

## Нефункциональные требования

- Проверка детерминирована, без модели. TDD: тесты `checkDebt` на каждое правило — до реализации.
- Поведение кода не меняется: правятся комментарии, `debt.md`, `migration.md`, `rules.md`, роли агентов и скрипты проверки.
- `bun run check` зелёный на каждой фазе.

## Критерии приёмки

- [ ] Все открытые записи DEBT имеют Место и Признак; формат описан в «Правилах».
- [ ] `checkDebt` покрыт тестами: устаревший glob, погашенный glob, долг вне Места, `DEBT-N` вне `biome-ignore`, неизвестный и закрытый ID, ARC-02 без маркера.
- [ ] В коде нет `DEBT-N` вне `biome-ignore` и нет `TR-NN`.
- [ ] Ни одного комментария «временн…» без записи в `debt.md`.
- [ ] Группы дублей слиты, закрытые ID помечены.
- [ ] Паттерн адаптера над legacy описан в `migration.md`.
- [ ] `bun run check` зелёный.

## За рамками

- Генерация документации из Def (`docs:domain`, `docs:llm`), вычистка JSDoc, дублирующего `label`/`description`.
- Линтер-запрет комментариев.
- Правка логики, погашение самих долгов.
- Долг пакета `dmg-core` (свой реестр).

## Риски

- Glob на модуль для DEBT-1/2 слабее маркера на импорт: новый импорт `core` внутри того же модуля не виден (принято).
- Признаки DEBT-35, DEBT-43 узкие и хрупкие; при неудаче — вопрос Нурболату, правило не ослаблять.
- Ф6 — суждение по каждому комментарию: новая запись — только через подтверждение, иначе долг теряется молча.
