# Бриф Ф5.2: недостающие e2e бота

Трек `revision-release_20261112`, строки F-10…F-34 [fixes.md](../fixes.md). Роль — `dmg-test-designer`. Список сценариев на файл — раздел этого файла в [e2e-gaps.md](../e2e-gaps.md) (ID, роль, вход); ожидание и ссылка на код v0.2.6 — та же строка в [reconcile.md](../reconcile.md) / [scenarios.md](../scenarios.md).

Цель — **характеризация**: e2e фиксирует путь сценария на **текущем** боте. Ожидание берётся из сценария (`scenarios.md`, ui-spec контроллера); где текущий бот ведёт себя иначе — тест пишется по ожиданию сценария, падает, и это **находка**, а не повод подогнать тест.

## Границы

- Можно: `runners/u7-bot/tests/e2e/*.e2e.test.ts` (дописать в существующий или создать новый — по `e2e-gaps.md`).
- Нельзя: прод-код, хелперы и миры (`tests/helpers/**`, `tests/worlds/**`) — нужен новый хелпер или данные мира → эскалация; `conductor/`, `data/`, `node_modules/`; коммиты.
- `../u7-school-v0.2.6` — только чтение (для уточнения ожидания).

## Харнес (Ф5.1)

- `createTestApp(tag, world, { clock: {} })` — управляемые часы (старт — якорь мира), `app.clock.advance(ms)`; `app.runJob(module, job)`.
- `TestBotTransport`: `chatMember`, `myChatMember`, `pressWithoutDialog`, `pressUnknownShortId`, `doubleTap`, `pressConcurrently`, `sendText`, `api.failNext(method)`, `answers`, `alerts`.
- Образцы — существующие файлы `tests/e2e/*` (стиль, миры, персоны); гайд — `conductor/architecture/ui/bot-test.md`.

## Правила

- Один `it` — один сценарий (или несколько ID одной ветки); в названии `it` — ID сценария (`P1-07: …`).
- Не дублировать уже покрытое: перед тестом проверь grep'ом по файлу, нет ли такого пути.
- Падает на текущем коде — не удаляй и не подгоняй: пометь `it.skip` с комментарием `// находка: <ID> — <что не так>` и вынеси в отчёт. Прод не чинить.
- Тексты экранов — из кода текущего бота (`runners/u7-bot/src/controllers/**`), не выдумывать.
- Не ослаблять типы (`as unknown as` — только с причиной в отчёте).
- Читай связанные файлы одним вызовом, не перечитывай прочитанное.
- ID реестра долга (`TR-<n>`, `DEBT-<n>`) в коде и комментариях запрещены — `arch:check` падает; ссылайся на ID сценария.

## Готово

- Во время работы: `bun test runners/u7-bot/tests/e2e/<файл>`.
- В конце: `bun run test:bot`, `bun run scripts/agent-gate.ts` — зелёные (skip допустимы только как находки).
- Тест кажется неверным — не правь чужой, опиши.

## Отчёт

По файлу: ID → `it` (покрыт / уже был покрыт `файл:строка` / находка); эскалации; итог команд.
