# Карточки «решение Нурболата» (ФР-4, ФР-5)

Одна карточка — одна запись группы «решение» из [triage.md](./triage.md) или обязательный пункт ревизии. Поле «Решение» заполняется только со слов Нурболата, с датой.

Шаблон:

```
## C-<nn>: <название> (<TR-n | DEBT-n | ФР-5>)
- **Суть:** что не так и почему это не тактика.
- **Варианты:** А — …; Б — …
- **Рекомендация:** вариант и причина; размер S/M/L.
- **Решение:** — (Нурболат, ГГГГ-ММ-ДД)
```
