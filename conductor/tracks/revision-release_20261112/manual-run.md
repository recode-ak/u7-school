# Ручная проверка текущего бота (ФР-3, Ф4)

Ключевые сценарии по персонам dev-мира `core-education` (`runners/u7-bot/tests/worlds/core-education.ts`). Ожидание — по [scenarios.md](./scenarios.md) (v0.2.6) с учётом `≠ намеренно` из [reconcile.md](./reconcile.md). Полный перечень путей без e2e — [e2e-gaps.md](./e2e-gaps.md); чек-лист их не дублирует.

## Подготовка

- Запуск: **только** `bun run dev:fixtures` (пересев `data/fixtures`, `DB_DIR=./data/fixtures`). Прямой `main.ts` запрещён: `.env.development` указывает на живые `data/`.
- Нужен `DEV_TELEGRAM_ID` в `.env.development`; проактивы всем персонам приходят в твой чат. `/persona` — список, `/persona <ключ>` — смена роли без рестарта.
- Персоны: `dev` — Алексей, ментор всех потоков мира и автор; `mentor2` — Виктор, ментор; `andrey` — студент Потока 2 (active); `marina` — Поток 2 (advanced); `oleg` — Поток 2 (not_advanced); `dmitry` — Поток 3 (advanced); `guest`; `candidate` — подписчик.
- Ограничения мира: персоны-админа нет (пути админа П5 — только e2e, `admin.e2e.test.ts` в Ф5); потоков с кодовым словом нет (P3-56…P3-60 — только e2e).
- Итог в столбце: `✅` / `❌ <что увидел>`. Находки `❌` оркестратор переносит в [regressions.md](./regressions.md) или помечает «намеренно».
