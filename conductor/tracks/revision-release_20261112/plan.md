Ревизия (Ф1–Ф4) только читает и документирует; исправления (Ф5) — по её итогам. Артефакты — в каталоге трека: `scenarios.md`, `reconcile.md`, `regressions.md`, `triage.md`, `cards.md`, `manual-run.md`, `fixes.md`, `rollout.md`.

Код — по TDD (red → запуск → green), конвейер [agents.md](../../architecture/agents.md) §3; исполнители — по [deepseek.md](../../architecture/deepseek.md) §2, метка в скобках у задачи. Стратегические вопросы — пачкой ([agents.md](../../architecture/agents.md) §9).

**Решения при планировании (Нурболат, 2026-11-12):**
- **Миры прогона.** Каждая версия сеет свой мир в свой `data/fixtures` (`bun run seed:fixtures` в своём worktree); общие фикстуры не используются — форматы разные, две версии агрегатов не сосуществуют. Worktree `../u7-school-v0.2.6` — только чтение, кроме собственного игнорируемого `data/fixtures`.
- **Прогон — поочерёдно**: сценарий на v0.2.6 → остановка → тот же на новом (один `BOT_TOKEN`, второй бот не заводится — релиз выкатывается взамен).
- **Push — разовый**, с отдельной остановкой и подтверждением перед `release.sh` (1299 коммитов и тег). Выкатка (вне трека): остановить старую → бэкап и миграция → запустить новую.

**Живые `data/` не трогаются.** `.env.development` в корне содержит `DB_DIR=./data` — запуск бота только через `bun run dev:fixtures`, прямой `main.ts` запрещён.
