Ты работаешь в worktree ветки `tst-cleanup` репозитория u7-school. Задача — **только чтение кода и запись одного файла**. Все тексты — на русском. Код и тесты не меняй.

1. `conductor/tracks/tst-cleanup_20261105/inventory/wish.md` — инвентаризация (кандидаты, закономерности З1–З8, «Что проверить перед удалением»).

## Решения, которые обязательны

- **Схемы (Б-8):** удаляются тесты приёма/отказа полей платформы. Остаются: своя логика схемы (`refine`/`transform`), отказ прежних форм записи (например legacy `courseId` вместо `target`), схема state, разбираемая при чтении файла, — одной таблицей «валидно/невалидно» на схему.
- **Паспорта Def (Б-7):** удаляются все. На модуль остаётся **один** тест состава: список UC (и ER/Job) модуля и `dependsOn`. Если такого теста нет — строка «переписать» с указанием, какой из удаляемых сократить до него.
- **Тексты `label` ошибок** не тестируются.
- **Бот:** integration — связка слоёв, e2e — пользовательская история. Тесты, красные сейчас из-за трека `course-dmg` (TR-57 в `conductor/architecture/debt.md`), **не удалять** — строка «отложить до course-dmg».
- Каждое удаление — только если указано, где покрыто то, что тест мог бы поймать. «Нигде» допустимо только для Б-9/Б-11/Б-12/Б-13 (тест не может поймать ошибку кода модуля) — тогда в колонке «где покрыто» объясни одной фразой.
