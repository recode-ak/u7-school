# Spec: app-assembly_20261029

## Обзор

До массового перевода модулей корень сборки DMG переносится из раннера в `@u7-scl/app` (DEBT-39, D-50/D-52), а шаг «вызовы после Policy» в жизненном цикле UC решается один раз (TR-27). Попутно — гигиена документации и тактических решений. Трек выполняется после `aggregate-meta_20261029`.

1. **TR-27:** решение D-NN в пакете — жизненный цикл UC `load` → Policy → правила → `fetch` (необязательный: чужие вызовы, нужные только после права) → `execute`. Реализация в `UseCaseFromDef`, учебный модуль (`assignTask`), гайд `use-case` (ловушка снимается); TR-27 закрыт.
2. **DEBT-39:** модули DMG собирает `@u7-scl/app` через `ApiApp` из `dmg-core/app` с резолвером `Caller`; раннер получает готовое приложение. Мосты legacy-фасадов (TR-11) переезжают вместе со сборкой.
3. Правила D-52: у `DomainArch` заданы `root` и `runners` (ARC-08 ловит импорт прикладных пакетов раннером); ARC-07 корневого `biome.json` совпадает с пакетом; ARC-09 — на всё, кроме точек входа раннеров; `rules.md` обновлён.
4. **TR-29:** `scripts/agents-sync.ts` — на `Role` из `dmg-core/cli` (или цель пакета с общим блоком — решается в задаче); второй разборщик удалён.
5. **TR-28:** устаревшие пути `platform/dmg-core/…` и «остатки legacy» в комментариях пакета вычищены; TR закрыт.
6. `migration.md` §6: «Старт следующих треков» и «Входной долг» — по факту; следующий трек — `stream-student`.
