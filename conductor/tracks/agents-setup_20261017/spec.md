# Spec: agents-setup — агентная среда для перехода на DMG

> Статус: **рабочая** (утверждена 2026-10-17 без замечаний; план ещё не составлен).

## Обзор

Трек 0 из [migration.md](../../architecture/migration.md). Готовит мультиагентный процесс из [agents.md](../../architecture/agents.md) в двух средах — Claude Code (основная) и pi (внешний исполнитель, D-24): роли пишутся один раз, гейт качества запускается автоматически, работа передаётся между средами через conductor и git. Тип: chore (инфраструктура).

## Функциональные требования

1. **Единый источник ролей** — `agents/<role>.md`: frontmatter `name`, `description`, `tools` (нейтральные имена: `read`, `write`, `edit`, `bash`, `grep`, `find`), опционально `model` по средам; тело — промпт роли.
2. **Генерация** — `bun run agents:sync` собирает `.claude/agents/<role>.md` и `.pi/agents/<role>.md`, переводя имена инструментов и моделей в формат среды. `--check` падает, если копии разошлись с источником; подключён к `bun run check`.
3. **Роли:** `domain-author`, `api-author`, `migrator`, `reviewer`. В каждой: выжимка правил слоя, ссылки на документы `conductor/architecture/` и ID правил, условия остановки (agents.md §7), запрет коммитов и правки `plan.md`, формат отчёта. Reviewer — без `write`/`edit`. Авторы помечены «доработать на эталоне golden-wish».
4. **Гейт в Claude Code** — хук `SubagentStop` в `.claude/settings.json`: `bun run check`; красный → exit 2, вывод ошибок возвращается субагенту.
5. **pi: субагенты** — subagent-расширение (на базе официального примера) в `.pi/extensions/subagent/`, `agentScope: "project"`; после каждого субагента расширение прогоняет `bun run check` и добавляет результат в ответ.
6. **Режим оркестратора** в `conductor-implement`: раздаёт задачи ролям по брифу среза (agents.md §5), сам гоняет гейт, единственный пишет `plan.md` и коммитит. Простые задачи вне перехода (legacy) — по-прежнему без субагентов.
7. **Передача между средами** в `conductor-implement`: старт — `plan.md` + `git log`, приёмка чужой работы гейтом и reviewer; остановка — коммит и отметка состояния незавершённой задачи в `plan.md`.

## Нефункциональные требования

- Генератор на Bun без новых зависимостей, покрыт тестами (TDD).
- Гейт укладывается в ~10 с (замер 2026-10-17: 9,3 с, 2816 тестов).
- Документы — по правилам `conductor-docs`; agents.md §8 обновлён по факту.

## Критерии приёмки

- `bun run agents:sync --check` зелёный; правка `agents/*.md` без пересборки ломает `check`.
- В Claude Code субагент-ревьюер виден в `/agents` и не может редактировать файлы.
- Пробный прогон в Claude Code: красный гейт возвращается субагенту, тот исправляет.
- Пробный прогон в pi: субагент запускается, результат гейта виден в ответе.
- Пробная передача: задача начата в одной среде и принята в другой по `plan.md` и `git log`.

## За рамками

- Генераторы `bun run gen` (трек generators), `arch:check` (трек core-dmg).
- ui-author.
- Выбор моделей для ролей — экспериментально, по умолчанию модель среды.
