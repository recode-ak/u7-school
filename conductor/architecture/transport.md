# Транспорт

**Назначение:** как манифесты превращаются во внешние контракты: HTTP, MCP, in-proc (бот, фасады). Реализация — треки потребителей графа (см. [migration.md](./migration.md)).

---

## 1. Общее

- Транспорт **генерируется** из Def: роутинг, валидация, описание контракта. Ручных ручек нет.
- Ответ — сериализованный `Result`:
  ```json
  { "ok": true, "value": { } }
  { "ok": false, "error": { "code": "STUDENT_NOT_ACTIVE", "kind": "conflict", "payload": { } } }
  ```
- Агрегаты передаются **снапшотом**; клиент восстанавливает их в `ReadonlyAr` (домен изоморфный: чистый и синхронный пакет работает и на сервере, и в клиенте).
- Маппинг `kind` → представление транспорта — **только в адаптере**, ошибка о нём не знает.

## 2. HTTP

- Всегда `POST /api/<module>` с телом JSON-команды:
  ```json
  { "uc": "complete-student", "input": { }, "meta": { "requestId": "…", "version": 1 } }
  ```
- `meta` — расширение без смены протокола: версионирование, трассировка, идемпотентность.
- `OPTIONS /api/<module>` — контракт модуля: UC с JSON Schema входа и выхода, ошибки, описание политики, `label`/`description`.
- Модуль в URL — для логов, прокси и будущего выноса модуля в сервис.

Маппинг `kind` → HTTP-статус (в адаптере):

| kind | Статус |
|---|---|
| `validation` | 422 |
| `unauthorized` | 401 |
| `access` | 403 |
| `not_found` | 404 |
| `conflict` | 409 |
| `internal` | 500 |

## 3. MCP

- UC → **tool**: `name` (`<module>.<uc>`), `description` из Def, `inputSchema` из JSON Schema; аннотации: query → `readOnlyHint`, command → `destructiveHint` по необходимости.
- Граф → **resources**: карта модулей (L0), страницы модулей (L1) и агрегатов (L2), каталоги событий и ошибок — чтобы LLM понимала модель, а не только список ручек.
- `Err` → результат tool с `isError` и текстом из `label`/`denyMessage`.
- Caller: старт — только query, dev-окружение, явно заданный `user` (D-18). Мутации и авторизация по токену — позже.

## 4. In-proc

- **UI (бот)** — `appApi.run(uc, input, caller)` → `Result`; story обрабатывает `Err` по `code`, презентер решает, как показать.
- **Фасады** — синхронный вызов в процессе; возвращают `Result` и `ReadonlyAr`. При выносе модуля в сервис тот же контракт идёт по HTTP, агрегаты — снапшотом.
- **CLI** (`scripts/call-uc.ts`) — тот же `appApi.run`.
