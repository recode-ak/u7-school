# <Вид артефакта> — гайд

**Назначение:** одно предложение — что это за артефакт и где он лежит (`packages/domain/src/<m>/…` или `packages/<m>/src/…`).

> Шаблон гайда эталона. Копируй в `<вид>.md`, заполняй по коду `wish` сразу после фазы, держи 40–80 строк. Код не вставляй — давай ссылки на файлы эталона. Ссылки и ID правил проверяет `scripts/guides-check.test.ts`.

## 1. Когда применять

3–5 пунктов: какая задача решается этим артефактом и когда выбрать другой (с ссылкой на соседний гайд).

## 2. Команда

`bun run gen <вид> <модуль>[.<агрегат>] [<имя>] [--adopt] --write` — что создаётся и какие `TODO` заполнить.

## 3. Эталон

Ссылки на файлы `wish` (контракт, реализация, тест) с одной строкой «на что смотреть».

## 4. Чеклист правил

ID из [rules.md](../rules.md), применимые к виду, — по строке «что проверить».

## 5. Типичные ловушки

Из ревью и ручной проверки фазы: симптом → как правильно.
