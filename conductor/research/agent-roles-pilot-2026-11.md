# Пилот ролей `dmg-*`: Claude Code против pi (2026-11)

**Цель:** проверить, что шесть ролей пакета `dmg-core` (волна 2, D-62 пакета) проходят конвейер среза на учебном модуле без специфики u7-school (критерий 6, [agent-roles.md](../architecture/agent-roles.md) §5), и сравнить две среды-оркестратора.

Трек: [agent-roles-wave2_20261104](../archive/agent-roles-wave2_20261104/), итог по фазе — `summary.md` трека, раздел «Пилот волны 2».

## Постановка

- Срез «Отложить задачу до даты» в учебном модуле `todo` пакета: поле отсрочки в `TaskState`, метод Ar, ошибки, событие, UC. Задание одно на обе среды — [pilot-task.md](../archive/agent-roles-wave2_20261104/pilot-task.md).
- Конвейер: `dmg-tech-lead` → `dmg-test-designer` → `dmg-domain-author` → `dmg-api-author` → `check` → `dmg-data-keeper` → `dmg-reviewer`.
- Временные worktree пакета от `de89c2f` с самоссылкой `node_modules/dmg-core → ..`. Человек и основная сессия по ходу не вмешивались.
- **Claude Code:** `claude -p`, оркестратор на Sonnet, роли по frontmatter (Opus — `dmg-domain-author`, остальные — Sonnet), `acceptEdits` с узким списком Bash.
- **pi:** `pi -p`, оркестратор и роли на `deepseek-flash`.

## Инциденты

- `claude -p` с `bypassPermissions` отклонён классификатором auto mode. С узким списком роли видели Bash «запрещённым», а `docs:*` не запускались.
- Пустой `claude-run.json` в корне worktree ронял `biome check .`: вывод запуска нельзя класть в проверяемое дерево.
- Расширение pi `subagent` не загружается вне u7-school (импорты `scripts/`, проектный гейт) — ограничение описано в [agents.md](../architecture/agents.md) §8.
- `pi -p` из фоновой команды без `< /dev/null` висит, ожидая stdin.
- `check` пакета — цепочка `&&`: красный `tsc` скрыл падения тестов ядра (заметил pi `dmg-api-author`).
- Тест графа ядра закреплял точный состав `todo`: любое расширение примера давало красный тест вне границ.

## Выводы

1. **Роли годны к переносу (критерий 6).** Ошибки ролей — пропуски проверок, а не непонимание платформы. Правки промптов внесены в пакет `6cfe5f2`.
2. **Claude Code быстрее и тщательнее как исполнитель:** втрое быстрее, вдвое больше тестов, ревьюер нашёл расхождение документов. Но тесты не по образцу именования и не проходили типы.
3. **pi на flash — лучше оркестратор, слабее ревьюер.** Оркестратор сам проверил `docs:*`, вызвал доп. тест по совету data-keeper, нашёл ложную `D-58`. Ревьюер на flash пропустил и документы, и `D-58` — совпадает с выводом [deepseek-ab-2026-11.md](./deepseek-ab-2026-11.md) (flash на шаг ниже).
4. **Автономность pi работает:** ни одного вопроса человеку, допущения записаны. Отступление — `git add -N` / `git restore --staged` для diffstat.
5. **Счётчики в прозе гайдов пакета** («пять UC») устаревают при каждом расширении примера; `docs:covers` этого не ловит.

## Рекомендации

- **Модели по ролям:** `dmg-reviewer` и `dmg-tech-lead` — не ниже Sonnet в любой среде; авторы и `dmg-test-designer` по образцу — flash допустим.
- **Среда:** интерактивная работа и ревью — Claude Code; длинные автономные прогоны по образцу — pi, вне u7-school — после доставки расширения `subagent` пакетом.
- **Headless Claude Code:** права задавать в `settings.json` worktree (включая `docs:*` и `bunx biome`), вывод запуска писать вне репо.
- **Пакет:** убрать счётчики из прозы `docs/guides/*.md` или сделать их машинной проверкой (ratchet) — кандидат в `debt.md` пакета.
- **`dmg-tech-lead`:** раздел «Документы» заполнять и при запрете их править — как «вне границ», с `docs:impact` (в `6cfe5f2` закрыто частично).

## Ограничения

- По одному прогону на среду; разброс моделей не измерен.
- Разные модели оркестратора (Sonnet и flash): сравнение сред смешано со сравнением моделей.
- Права Claude-прогона искусственно сужены, часть сбоев — от них.
- Стоимость субагентов pi не записана в сессии.
- Артефакты (брифы, отчёты, код среза) удалены вместе с worktree; здесь — выжимка.
