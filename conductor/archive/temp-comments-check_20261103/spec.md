# Spec: проверка «временных» комментариев в `arch:check`

Источник: кандидат ../../roadmap/temp-comments-check.md (ревью Ф6 трека `debt-markers_20261103`).

## Обзор

`checkDebt` ловит `DEBT-N` вне `biome-ignore`, `TR-NN` в коде и долг по Признаку вне Места записи. Временный код с маркером («Временное решение», «ВРЕМЕННЫЙ», «Уходит с миграцией») проходит незамеченным, если его нет в `debt.md`. Трек добавляет проверку: строка с маркером вне Места открытой записи реестра — ошибка.

## Функциональные требования

1. Проверка — приватный метод `DebtRegistry.checkTempMarkers` в `scripts/domain-check.ts`, вызывается из `DebtRegistry.check` (ООП, опора на те же данные реестра). `scripts/arch-check.ts` не меняется: проверка подключается через `runDebtCheck`.
2. Узкий список маркеров: «Временное решение» и «Уходит с миграцией» — без учёта регистра; «ВРЕМЕННЫЙ» — **только заглавными**. «временный», «временные метки», «одновременно», «временном каталоге» не срабатывают (отсекаются составом фраз и регистром, не `\b` — он не работает для кириллицы).
3. Единица проверки — **строка с маркером** (как у `checkDebt` и `checkTrMarkers`: построчный поиск по тексту файла, комментарии от кода не отличаются).
4. Маркер допустим только в файле из Места **открытой** записи `debt.md`. Запись «слит в» (закрытая) маркер не оправдывает. Иначе ошибка: `DEBT: <path>:<line>: маркер временности «…» вне Места открытой записи — заведи запись в debt.md или убери комментарий`.
5. Область — как у `checkDebt` (`readPackageSources`): `*/src/**` и `domain/src/**`. Тесты в `src` пакетов проверяются; тесты `scripts/` и `runners/*/tests` — нет.
6. Строгий режим сразу: в области сейчас 0 совпадений.
7. Тесты в стиле `scripts/domain-check.test.ts`, TDD (red → green).

## Нефункциональные требования

- Без новых зависимостей, простые типы, сообщения на русском в формате соседних проверок.
- Данные `data/` не затрагиваются, чужие контракты не меняются.

## Критерии приёмки

- [ ] Маркер вне Места: `arch:check` падает с сообщением (путь, строка, подсказка).
- [ ] Маркер в Месте открытой записи — ошибки нет; в Месте закрытой («слит в») — ошибка есть.
- [ ] «ВРЕМЕННЫЙ» заглавными ловится, «временный»/«временные метки»/«одновременно»/«временном каталоге» — нет; две другие фразы ловятся без учёта регистра.
- [ ] `bun run check` и `bun run arch:check` зелёные на репозитории без новых нарушений.
- [ ] `conductor/architecture/debt.md` описывает проверку маркеров.
- [ ] Кандидат снят из `conductor/tracks.md`, `conductor/roadmap/temp-comments-check.md` удалён.

## За рамками

- Расширение списка формулировок, общий поиск слова «временно».
- Автосоздание записей в `debt.md`; изменение формата Место/Признак/Корень.
- Проверка `.md`, `.json`, контента курсов, тестов `scripts/` и `runners/*/tests`.
