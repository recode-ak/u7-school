# Spec: tst-cleanup_20261105

## Обзор

Кандидат из test-bloat.md. При переносах число тестов растёт без роста функционала. Известен один сценарий (одно правило проверяется на двух уровнях); цель — найти остальные закономерности «пустых» и околопустых тестов, зафиксировать признаки и почистить модули.

## Решения (Нурболат, 2026-11-05)

- **Ветка.** Трек идёт в ветке `tst-cleanup`, worktree `../u7-school-tst-cleanup`. На `main` его коммитов нет, пока не закрыт `course-dmg`: история и базовая линия `course-dmg` не смешиваются. Вливание — после закрытия `course-dmg`, с поправкой его базовой линии.
- **Границы чистки:** `wish`, `stream`, `questionnaire`, `peer-review`, `user`, `dossier` — домен, модуль и их тесты в `runners/u7-bot`.
- **Не чистим:** `course` и тесты бота по курсу — их меняет `course-dmg` (Ф4–Ф5). Читать для анализа можно; итог — рекомендации в `test-bloat.md` для будущего трека по `course`.
- **Исполнители.** Инвентаризация, таблицы удаления и удаление — DeepSeek `flash` через `scripts/pi-role.ts` ([deepseek.md](../../architecture/deepseek.md)). Opus — синтез закономерностей по таблицам и приёмка таблиц удаления. Бюджет Claude — 3–5% недельной квоты; превышение после Ф1 — остановка и вопрос.
- **Правила тестов** (ответы на вопросы синтеза Ф1): уровень «Схемы» — только своя логика схемы; ручные паспорта Def удаляются, на модуль — один тест состава (UC + `dependsOn`); тексты `label` ошибок не тестируются — пакет, TST-09 / D-67 (`dmg-core` `eea2a24`). Integration — связка слоёв, e2e — пользовательская история «без фанатизма» — `conductor/architecture/ui/bot-test.md` §2.
- **Удаление — только по принятой таблице** «тест → почему лишний → где покрыт (путь до `it`)».

## Критерии

- Закономерности с признаками поиска — в `test-bloat.md` §2; правило, если следует, — в `testing.md` пакета или проектный документ.
- Раздел рекомендаций для `course` в `test-bloat.md`.
- Число тестов падает; покрытие строк затронутых исходников (`bun test --coverage`) не падает; `check` зелёный.
