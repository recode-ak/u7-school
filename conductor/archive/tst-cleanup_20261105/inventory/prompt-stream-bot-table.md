## Решения, которые обязательны (общие)

- **Схемы (Б-8):** удаляются тесты приёма/отказа полей платформы. Остаются: своя логика схемы (`refine`/`transform`), отказ прежних форм записи, схема state, разбираемая при чтении файла, — одной таблицей «валидно/невалидно» на схему.
- **Паспорта Def (Б-7):** удаляются все. На модуль остаётся **один** тест состава: список UC (и ER/Job) модуля и `dependsOn`. Если такого теста нет — строка «переписать».
- **Тексты `label` ошибок** не тестируются (TST-09). Одиночные `expect` на `label` внутри полезных тестов — отдельным разделом «Остающиеся проверки `label`» (файл:строка `expect`), как в `wish-delete.md`.
- **Одно правило на двух уровнях (Б-1):** правило проверяет владелец (Ar / DCS / DQS / Policy домена). У UC модуля остаются: один сквозной сценарий на UC и то, что делает только UC (загрузка, Policy-отказ, своя ошибка, запись в UoW, публикация).
- **Бот:** integration — связка слоёв, e2e — пользовательская история. Тесты, красные сейчас из-за трека `course-dmg` (TR-57 в `conductor/architecture/debt.md`), **не удалять** — строка «отложить до course-dmg».
- Каждое удаление — только если указано, где покрыто то, что тест мог бы поймать. «Нигде» допустимо только для Б-9/Б-11/Б-12/Б-13 — тогда в колонке «где покрыто» объясни одной фразой.
- **Б-13 (тест мёртвого экспорта):** действие `отложить: удалить с кодом` — тест не трогаем, код удалит отдельная задача.
