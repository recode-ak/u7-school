# Спецификация: аудит тестов типов `dmg-core` (Б-17)

## Обзор
Позитивные тесты типов в `dmg-core` дублируют `tsc`-проверку рабочего кода. Негативные `@ts-expect-error` на публичные гарантии платформы держат то, что больше ничем не проверено. Трек чистит тесты типов пакета по правилу §2 разбора-кандидата (после трека — TST-10 пакета, `dmg-core/docs/reference/testing.md` §5.2) и закрепляет это правило в документации пакета. Тип — chore, публичный API не меняется.

Объём на 2026-11-11: `~/dev/tools/dmg/dmg-core/src` — 34 файла, 72 `@ts-expect-error`, 81 `expectTypeOf`/`Equal` (153 случая). В u7-school в `modules/course` тестов типов уже нет: их убрал `course-dmg`. Остались 5 случаев в legacy `platform/core`.

## Функциональные требования
1. **Инвентаризация (DeepSeek flash, только чтение).** Таблица всех 153 случаев: файл:строка, вид (позитивный, негативный, рантайм-ветка), какую гарантию проверяет, есть ли использование в `src/` или `src/testing/example/`, вердикт («удалить», «оставить», «сузить», «оценить как обычный тест»).
2. **Приёмка таблицы (Opus).** Сверить вердикты с правилом §2. Спорные случаи показать Нурболату.
3. **Удаление** позитивных тестов, чей вывод использует `src/` пакета или `src/testing/example/`.
4. **Сужение** голых `@ts-expect-error`: пояснение и ровно одна ожидаемая ошибка в строке.
5. **Рантайм-ветки** (`@ts-expect-error` ради неизвестной команды, `as never`) оценить как обычные тесты по критериям TST-08. Лишние удалить, закономерность записать в журнал [test-bloat.md](../../roadmap/test-bloat.md).
6. **Правило §2** записать в `docs/testing.md` пакета.
7. **Заготовку закрыть:** снять кандидата Б-17 из `tracks.md`, `roadmap/type-tests.md` закрыть по `conductor-docs`.

## Нефункциональные требования
- Правка — в репо `~/dev/tools/dmg/dmg-core`, порядок — по [architecture/index.md](../../architecture/index.md) («Правка платформы `dmg-core`»). Версия остаётся `0.1.1`, SHA пакета указывается в коммите u7-school.
- `check` пакета и `check` u7-school остаются зелёными. Число тестов сравнивается с базовой линией.
- Инвентаризацию и механическое применение выполняет DeepSeek flash по [deepseek.md](../../architecture/deepseek.md).

## Критерии приёмки
1. У каждого из 153 случаев есть принятый вердикт в таблице, таблица лежит в папке трека.
2. В `dmg-core/src` не осталось позитивного теста типа, чей вывод использует `src/` или `src/testing/example/`.
3. Каждый оставшийся `@ts-expect-error` снабжён пояснением, и под ним ровно одна ошибка.
4. Негативные тесты на гарантии из §2 (Def вне `calls`, ошибка вне Meta, мутация `ReadonlyAr`/`state`, команда чужого модуля) на месте.
5. Правило записано в `docs/testing.md` пакета, `llms.txt` при необходимости обновлён.
6. `check` зелёный в обоих репо. Разница с базовой линией объяснена удалениями из таблицы.
7. Кандидат Б-17 снят из реестра, разбор закрыт.

- Изменения публичного API и типов пакета.
