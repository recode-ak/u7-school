# Ошибка seed:fixtures после перехода на тестовые миры

## Симптомы
`bun run seed:fixtures` или `bun run dev:fixtures` падает с ошибкой `ENOENT: no such file or directory, copyfile '.../apps/u7-bot/tests/fixtures/templates/users.json'`.

## Причина
В треке `test-worlds` ручные JSON-шаблоны в `apps/u7-bot/tests/fixtures/templates/` были удалены в пользу генерации из миров, но скрипт `apps/u7-bot/scripts/seed-fixtures.ts` оставался на старом коде копирования файлов.

## Решение
Использовать `seedWorldFixtures` из `../tests/worlds` в `apps/u7-bot/scripts/seed-fixtures.ts`, который материализует декларативный мир (по умолчанию `core-education` или заданный через `WORLD=...`) в `data/fixtures/`.
