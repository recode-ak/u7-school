# Использование синхронных API файловой системы для начальных курсов
## Симптомы
Студенты на ранних этапах обучения еще не знакомы с промисами, async/await и Event Loop, поэтому асинхронные файловые функции вызывают ступор.

## Решение
Использовать синхронные функции `readFileSync` и `writeFileSync` из стандартного модуля `node:fs` вместо асинхронных методов Bun API.

## Почему это работает
Позволяет изучать сохранение данных на диск линейно, без погружения в асинхронное программирование и синтаксис `await` до прохождения темы промисов.

## Подводные камни
Синхронный ввод-вывод блокирует основной поток, но для учебных CLI-утилит и скриптов в рамках одного потока это приемлемо и упрощает ментальную модель.
